# 取点遮罩与坐标精度（FR-27）

本文记录 R1 取点遮罩的交互、坐标规则、性能口径和验证边界。

## 1. 交互

- 打开后整个虚拟屏变暗 40%，十字线跟随鼠标，主屏右上角显示 5×5 像素放大镜与 `5×5 (x, y)` 坐标。
- 按下拖拽取矩形；拖拽位移 ≤4px 时按单击处理，回填 1×1 点。
- 方向键微调 1px，Shift+方向键微调 10px；点或矩形整体平移，尺寸不变，并被限制在虚拟屏内。
- 光标或选区靠近虚拟屏/显示器边缘 8px 时自动吸附；右边界吸附到 `right-1`，下边界吸附到 `bottom-1`，避免落到屏幕外。
- Enter / 小键盘 Enter 确认并回填；Esc 取消，原值不变；右键只清空当前选框，不关闭遮罩。
- 顶部提示固定在主屏顶部中央；尺寸标签跟随选框右下角；放大镜固定在主屏右上角，避免覆盖中央取点区。

## 2. 多显示器与负坐标

- Windows 用 `GetSystemMetrics(76..79)` 获取虚拟屏原点与尺寸，用 `SetWindowPos` 把遮罩放到虚拟屏原点。
- 显示器矩形用 `EnumDisplayMonitors` 获取，作为内部吸附边；失败时退化为整个虚拟屏。
- 坐标统一使用桌面绝对坐标，允许负值；选区和放大镜框均以虚拟屏边界钳制。

## 3. 性能

- 启动时调用 `prewarm_region_selector`，在隐藏 Toplevel 中建好并销毁一次完整控件树，提前加载字体与控件类，避免首次取点卡顿。
- 遮罩先 `withdraw`，后台线程用 `ImageGrab` 抓桌面；主线程每 20ms 轮询，最多等 300ms，无论抓屏是否成功都会显示遮罩。抓屏不会阻塞 UI，也不会把遮罩自身抓进放大镜。
- 显示时使用局部 `grab_set`，不使用 `grab_set_global`；本机实测全局抓取首次显示会阻塞约 2.8s，且会跨进程抢占输入。
- 实测（2026-11-23，源码构建 003 环境）：预热后遮罩构造 2.4–6.8ms，显示 36–238ms；Windows 全屏 Toplevel 首次映射受桌面调度/安全软件影响波动较大。GUI 冒烟以 100ms 为目标打印告警，回归硬阈值 400ms，用于捕获数量级退化。

## 4. 验证边界

- 当前桌面会话拒绝 `ImageGrab.grab(all_screens=True)`（`OSError: screen grab failed`），Win32 `BitBlt` 也返回空位图；因此本机只能验证降级棋盘格、坐标、十字线、选框和键盘路径。
- 放大镜的真实 5×5 像素需在有桌面像素访问权限的会话中人工复核；抓屏成功时使用最近邻放大并叠加 5×5 网格与中心红十字，失败时显示灰蓝棋盘格。
- 测试环境变量 `AUTOCLICKER_PICKER_NO_CAPTURE=1` 仅用于跳过抓屏，不代表真实运行路径。
