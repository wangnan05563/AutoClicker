复核方式：对主程序 `D:\code\otherProjects\AutoClicker\auto_clicker_py3.py` 和 `auto_clicker_layers` 下全部 Python 文件做大小写不敏感关键词扫描，产品代码命中 0；仅 `tests` 中有无关的 `update` 字样。

3. 减少动效需要持久化设置，并在页面切换/列表滚动/提示动画处统一短路；保留功能可用性，不做“只删动画导致布局跳动”。
4. 色弱模式需要调色板 + 形状/图标/文字冗余编码，不能只换颜色；需覆盖运行状态、命中/失败、选中态。

缺陷登记与修复建议：

1. 多语言先做资源抽取和 `zh-CN/en-US` 两套词条，再补英文界面截图比对；验收必须覆盖无中文残留、无截断。
2. 更新提示复用 AC-38 的版本清单，先做只读提示和下载链接；不要在没有签名校验前做自动安装。
3. 图像条件等待应作为宏的新 step 类型（截图区域、模板、阈值、超时、失败策略），超时必须告警并停止后续点击。
4. CLI 用 `argparse` 增加 `--profile`、`--run`、`--exit-after` 等参数；GUI 与 CLI 共用执行引擎，退出码区分成功/参数错误/运行时错误。
5. MCP 需要本地鉴权 token、工具白名单、调用审计；未授权请求返回拒绝并记录，不暴露文件系统路径。
6. 文本扩展需要独立词条文件、触发前缀、展开后中文编码测试；验收覆盖 5 条缩写与乱码边界。
