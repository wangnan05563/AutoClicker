## 2. 复验中发现并修复的真实缺陷

1. `_ui()` 只接受 `*args`，点击线程传 `value=/text=` 时抛 `TypeError`，点击线程倒计时后崩溃、统计恒空。改为 `_ui(self, fn, *args, **kwargs)`。
2. 启动只更新顶部状态，底部状态条与窗口标题仍「已停止」。新增 `_do_set_status()` 统一三处。
3. `_read_interval()` 只校验下界，`3601` 可通过，与「1-3600」不符。补 `>3600` 拦截。
4. 配置迁移前不备份；新增 `_backup_config_before_migration()`，`config_version<2` 或坏 JSON 时先复制原文件。
5. Wayland 降级文档缺少 PRD §2.3「不做项」清单；新增第 6 节逐条对齐。
6. 自动停止（点击上限/failsafe）在点击线程内调用 `stop_clicking()`，`join` 自身抛 `cannot join current thread`，状态条/按钮/休眠恢复全部未执行。改为仅当前线程不是点击线程时才 join。

## 5. 复验口径说明

- 本轮不是鼠标人工点击，而是运行真实 Tk 窗口与真实事件循环，仅将系统级点击/光标/休眠副作用替换为记录桩；因此能验证 UI 状态机、线程、配置、日志、参数传递，但不能替代「物理键盘按键」和「真实目标窗口响应」。
- F8/Esc 的 `keyboard.press_and_release` 与 `keybd_event` 合成事件均未触发全局钩子，因此相关任务维持 `verified=false`，不虚标通过。
- 截图 `ac_ui.png` 为空白白图（ImageGrab 未抓到窗口），本轮证据以控件状态、日志、JSON 报告与文件断言为准。
