# AutoClicker 启动性能 AC-16 硬约束结论（T06166 / T06328）

- 日期：2026-11-26
- 结论：**AC-16（onedir 10 次冷启动中位数 <3s）未通过，且在当前本机环境与现有发布条件下无法稳定达成**
- 任务处置：T06328 按“不能达标时记录硬约束”收口；T06166 按“验收未通过”收口；均不标 verified，不宣称 AC-16 通过

## 一、口径

- AC-16：Given onedir 构建，When 冷启动 10 次，Then 中位数 <3s。
- 本报告沿用“进程启动到第一个可见、有标题的顶层窗口”的探针口径，超时 60s 记为 60s。
- 005 的 10 次样本中位数 23.95s 来自 T06166 处理结果；原始 `release/startup-bench-20261124-001.json`、`release/build-005.log` 当前不在工作区，**不能同文件复核**，因此只作为历史阻塞证据，不作为本轮基线。

## 二、本轮实测（构建号 20261126-002）

隔离产物：`D:\tmp_ac_sign\dist\AutoClicker`，onedir 1029 文件 / 44.56 MB。

| 场景 | 样本（秒） | 中位数 |
|---|---|---|
| 未签名，普通 Defender 实时保护 | 60.103 / 34.608 / 11.318 | 34.608 |
| 未签名，暖启动复测 | 19.763 / 23.692 / 14.934 | **19.763** |
| 未签名，整个测试根目录排除 | 10.047 / 6.159 / 5.301 | 6.159 |
| 未签名，进程级排除 | 4.971 / 3.982 / 5.532 | **4.971** |
| 已签名（临时自签），普通 Defender | 25.433 / 21.018 / 27.325 | 25.433 |
| 已签名，进程级排除 | 8.980 / 5.457 / 7.137 | 7.137 |
| 记事本基线 | 4.422 / 1.804 / 1.364 | 1.804 |

同源码分段计时：`ROOT_READY=0.84s`、`INIT=2.55s`、`TOTAL=2.73s`，`setup_ui=0.67s`。

## 三、归因

1. **Defender 实时扫描是主要贡献项**：未签名暖启动 19.763s，进程级排除后 4.971s，减少 14.792s（74.8%）。
2. **不是唯一原因**：排除后最好样本 3.982s、中位数 4.971s，仍高于 3s；相对源码 2.73s，PyInstaller onedir 运行时约有 2.2s 固定开销。
3. **自签名没有帮助**：84 个 PE 全部签名后，普通 Defender 25.433s，反而比未签名暖启动慢 5.670s；排除后 7.137s，也慢 2.166s。自签证书链/未知发布者校验带来额外开销，不能代表真实 OV/EV 或 Microsoft Trusted Signing。
4. **测试主机不是干净基线**：`MsMpEng` 空闲期仍占 85.8%–201.6% 单核 CPU；记事本中位数 1.804s。绝对启动数值有噪声，不能把 4.971s 当作干净机器结论。

## 四、为什么当前无法达标

- 3s 阈值包含 Windows 实时保护对 1029 个文件的首次/变更扫描；本机未部署白名单，发布包也没有真实受信任签名。
- 即使人为做进程级排除，仍在 4–5s；只靠 Tcl 数据裁剪不能解决：全量裁剪后中位数 6.534s，仅降 19.4%，且删 `msgs` 有本地化文案风险。
- 真实 OV/EV / Trusted Signing 证书、干净 Windows VM 基线、部署侧白名单策略均未具备；在这些条件补齐前，不能证明 AC-16 可达。
- onefile 不作为候选：多次只出现标题为 `Error` 的窗口或 60s 无主窗口，不能作为可用产物。

## 五、处置决定

- T06328 不再继续无效调参；按任务描述“若仍不能达标，记录拆解后的瓶颈与不能达标的硬约束”收口，`status=done`、`verified=false`。
- T06166 作为验证母单同步收口：验收结论为 **FAIL**，AC-16 仍未通过；`status=done`、`verified=false`。
- 不把 Defender 排除、自签名、Tcl 裁剪写成“已达标方案”；发布包仍保持未签名 onedir。
- 性能门槛若必须继续推进，需要产品侧先裁决：是否允许部署白名单/排除，或把“首次 AV 扫描”和“暖启动”拆成两个验收口径；否则 3s 在本环境不可稳定达成。
