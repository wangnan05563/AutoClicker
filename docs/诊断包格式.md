# 诊断包格式与脱敏边界（FR-03）

设置页「诊断中心」用于把输入后端、热键、自启、权限、打包资源等现场信息集中展示，并给每项异常附可执行修复步骤。诊断包只用于本地排障，不会自动上传，也没有遥测。

## 1. 生成方式

- 设置页 →「诊断中心」→「一键复制诊断包」
- 输出目录：`~/.auto_clicker_diagnostics/`
- 文件名：`AutoClicker-diagnostics-YYYYMMDD-HHMMSS.zip`
- 生成后会把 zip 的绝对路径复制到剪贴板；同一秒重复生成时自动追加序号

也可点击「查看详情」阅读完整检查项和修复步骤，或「打开诊断目录」直接查看历史包。

## 2. zip 结构

| 文件 | 内容 |
|---|---|
| `diagnostics.json` | schema `autoclicker.diagnostics/1`，总体状态、生成时间、应用版本/构建号、检查项与修复步骤 |
| `summary.txt` | 供人工阅读的纯文本摘要，与 JSON 同源 |
| `config.json` | 配置白名单摘要（间隔、模式、次数/时长上限、热键、主题、自启等） |
| `logs/app.log.tail.txt` | 应用日志最后 60 行（脱敏后） |
| `logs/crash.log.tail.txt` | 崩溃日志最后 60 行（脱敏后；存在时才生成） |
| `manifest.json` | 文件清单、字节数与 `sanitized: true` 标记 |

## 3. 检查项

| ID | 检查 | 异常时的指引 |
|---|---|---|
| `input` | 鼠标输入后端 / Wayland / X11 / Windows 会话 | Wayland 安装并启动 `ydotoold` 或切 X11；X11 安装 python-xlib；Windows 从交互桌面会话启动 |
| `hotkey` | F6/F8/Esc 是否注册成功、是否同键冲突 | 换 F7/F9；关闭游戏/输入法/显卡驱动同名热键；重新应用 |
| `autostart` | 开机自启配置与系统自启项是否一致 | 检查 HKCU Run 写权限；关闭再开启；路径失效时重新写入 |
| `permission` | 配置、日志、诊断目录是否可写 | 检查目录权限，避免受保护目录，关闭安全软件目录拦截 |
| `packaging` | onedir `_internal`、pywin32、图标资源是否完整 | 重新安装完整包；不要只复制 exe |
| `crash` | `crash.log` 是否存在 | 复制诊断包并附带复现步骤 |
| `session` | 平台、会话、DPI、屏幕尺寸 | 信息项，用于复现环境 |
| `config` | 启动键与急停键是否分离 | 改为不同按键并保存 |

## 4. 脱敏边界

诊断包**不包含**：

- 点击坐标、区域尺寸、多点位列表；
- 前台窗口标题或窗口关键字；
- 配置方案名称、完整配置文件；
- 完整日志（只取最后 60 行）；
- 用户名、用户主目录的完整路径；
- 密码、token、cookie、API key 等凭据字段。

写入前会对报告和日志尾部再次做递归脱敏，替换 `<用户目录>` / `<用户>` / `<已隐藏>`。`manifest.json` 始终标记 `sanitized: true`。

## 5. 已知限制

- 诊断只反映当前进程和当前会话，无法回溯已退出的进程；
- 日志尾部可能包含用户自定义提示文本，提交前仍建议人工浏览 `summary.txt`；
- 诊断包不替代 8 小时稳定性、内存或真机兼容矩阵测试。
