## 1. 已实现

### 1.1 版本号单一来源
- `package.json` 的 `version` 为构建版本号唯一来源，由 `scripts/patch_version.py` 在每次构建前分配 `YYYYMMDD-序号`。
- `auto_clicker_py3.py` 新增 `get_app_version()`：源码运行读项目根 `package.json`；PyInstaller 打包后优先读 `sys._MEIPASS/package.json`，再读 exe 同目录；均缺失时回退常量。
- `python auto_clicker_py3.py --version`（或 `-V`）直接输出版本，不创建 Tk 窗口，可用于发布包冒烟与运维排查。
- `scripts/config.build.json` 的 `pyinstaller.add_data` 增加 `package.json → .`，确保 onefile 包内带版本文件。

### 1.2 离线升级清单
新增 `scripts/release_manifest.py`：

```powershell
# 生成清单（默认 release\manifest.json）
python scripts\release_manifest.py --exe release\dist\AutoClicker.exe
# 目标机校验（不覆盖清单）
python scripts\release_manifest.py --exe D:\upgrade\AutoClicker.exe --out manifest.json --verify
```

清单字段：`product/version/platform/arch/filename/size/sha256/generated_at`。离线升级流程：

1. 在构建机生成 exe 与 `manifest.json`；
2. 一起拷到目标机（U 盘/内网共享均可）；
3. 目标机先 `--verify`，版本、大小、SHA256 全一致才替换旧 exe；
4. 替换后运行 `AutoClicker.exe --version` 复核，再启动 GUI。
