## 1. 需求
PRD FR-D01：每日 HH:MM 自动启动、运行 N 分钟后停止、仅工作日；跨零点与休眠唤醒后补算；验收“设定 2 分钟后自动启动，误差 <2 s；系统休眠唤醒后计划仍生效”。

## 2. 实现
文件：`D:\code\otherProjects\AutoClicker\auto_clicker_py3.py`

- 配置新增 `schedule: {enabled, start_at, stop_after_min, weekdays}`，旧配置自动补齐。
- UI「高级 (P1)」新增一行：定时计划开关、启动 HH:MM、运行分钟数、每天/工作日/周末、应用计划按钮与下次运行提示。
- `_schedule_tick()`：Tk 主线程每秒检查；用 `time.monotonic()` 差值识别系统休眠/卡顿（>90s 记日志并补算）。
- `_schedule_check()`：
  - 取昨天/今天中 <= 当前时间、且日期为选中工作日的最近一次计划，天然支持跨零点；
  - 未运行时在窗口内触发启动；`stop_after_min=0` 给 5 分钟补算宽限，>0 时窗口到 `start + N 分钟`；
  - 同一 occurrence 只启动一次，用户手动停止后当日不重复拉起；
  - 定时启动的运行在 `start + N 分钟` 自动调用 `stop_clicking(reason=...)`；
  - 计划关闭时清空活动标记，不干预手动运行。
- `on_schedule_apply()` 校验时间/分钟/星期并持久化；非法值弹窗，不写入配置。
- `apply_config_to_ui()` 支持方案切换后回填定时字段。
