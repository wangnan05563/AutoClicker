1. 新增一次性执行报告、逐次日志、中间构建记录不进入 `docs/` 根目录；需要保留时放到 `docs/evidence/` 并在对应验收文档中引用。

3. 旧版本文件不长期保留；依赖 git 历史追溯，避免 docs 再次膨胀。
