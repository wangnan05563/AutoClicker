# AutoClicker 用户主题包格式（FR-35）

AutoClicker 支持在界面「主题」下拉框旁点击「导入主题」，选择本地 JSON 文件。校验通过后，主题会复制到：

```
~/.auto_clicker/themes/<主题 id>.json
```

导入后立即出现在主题下拉框，并自动切换、持久化到 `theme_pack`。

## 最小示例

```json
{
  "schema": "autoclicker.theme/1",
  "id": "my_theme_01",
  "name": "我的主题",
  "mode": "dark",
  "colors": {
    "bg": "#1b1f24",
    "surface": "#232930",
    "surface_alt": "#2c333b",
    "text": "#f1f3f5",
    "muted": "#aeb6bf",
    "primary": "#4a90d9",
    "primary_hover": "#3d7ab8",
    "primary_pressed": "#326596",
    "on_primary": "#0b0f14",
    "success": "#2ecc71",
    "danger": "#f16c6c",
    "warning": "#e67e22",
    "border": "#66707a",
    "focus": "#4a90d9"
  },
  "typography": {
    "font_family": "微软雅黑",
    "mono_family": "Consolas",
    "scale": 1.0
  },
  "meta": {
    "author": "your name"
  }
}
```

## 字段规则

| 字段 | 必填 | 说明 |
|---|---|---|
| `schema` | 是 | 固定为 `autoclicker.theme/1` |
| `id` | 是 | 3–32 位小写字母/数字/下划线/短横线，必须以字母开头；不能与内置主题 `light`、`dark`、`high_contrast`、`ocean`、`sand` 重名 |
| `name` | 否 | 下拉框显示名；缺省使用 `id` |
| `mode` | 否 | `light`、`dark`、`high_contrast`，决定深色控件与 ttkbootstrap 基底；缺省 `light` |
| `colors` | 是 | 必须包含下列 14 个颜色令牌，全部为 `#RRGGBB` |
| `typography` | 否 | `font_family`、`mono_family`、`scale`，当前仅保留字段，后续版本生效 |
| `meta` | 否 | 作者、版本等自定义信息 |

## 14 个颜色令牌

`bg`、`surface`、`surface_alt`、`text`、`muted`、`primary`、`primary_hover`、`primary_pressed`、`on_primary`、`success`、`danger`、`warning`、`border`、`focus`。

建议 `text/bg`、`muted/bg`、`on_primary/primary`、`on_success/success`、`on_danger/danger`、`on_warning/warning` 的 WCAG 对比度不低于 4.5:1。内置 5 套主题已按此标准校验。

## 安全边界

- 只允许 JSON 数据，不执行脚本；
- 顶层键只允许 `schema`、`id`、`name`、`mode`、`colors`、`typography`、`meta`；
- 任意字段名包含 `script`、`url`、`path`、`command`、`exec`、`shell` 都会被拒绝；
- 颜色不接受函数、渐变、URL 或图片路径，只接受十六进制色值。

## 删除主题

退出 AutoClicker 后删除 `~/.auto_clicker/themes/<主题 id>.json`，下次启动即不再加载。
