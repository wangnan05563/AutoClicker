# 桌面自动点击工具

一个功能强大的桌面自动点击工具，支持自定义点击间隔、点击区域设置、防锁屏等功能。

## 功能特性

### 核心功能
- ✅ 自定义点击间隔时间（1-120分钟）
- ✅ 支持三种点击模式：随机位置、中心点、自定义区域
- ✅ 防止系统自动锁屏
- ✅ 开机自动启动
- ✅ 后台低资源运行
- ✅ 快捷键控制（F6）

### 高级功能
- 📊 实时状态显示
- 📝 日志记录
- ⚙️ 配置文件保存
- 🎯 点击区域自定义设置
- 🔄 错误自动恢复

## 系统要求

- Windows 10/11 或 macOS 10.14+
- Python 3.7+

## 打包结果

打包成功！可执行文件位于：
```
build\exe.win-amd64-2.7\AutoClicker.exe
```

整个 `build\exe.win-amd64-2.7` 文件夹需要一起分发，包含：
- `AutoClicker.exe` - 主程序
- `lib/` - 依赖库
- `tcl/` - Tk界面库
- `python27.dll` - Python运行时

## 使用方法

1. 直接双击 `AutoClicker.exe` 运行
2. 设置点击间隔（分钟）
3. 选择点击模式（随机/中心/自定义区域）
4. 点击"Start"启动自动点击
5. 按 F6 快捷键可快速启动/停止

## 注意事项

- 本程序使用 Python 2.7 + cx_Freeze 打包
- 需要整个 `exe.win-amd64-2.7` 文件夹一起使用
- 如需单独的 exe 文件，可使用 PyInstaller（需要 Python 3.x 环境）

## 使用说明

### 基本操作

1. **设置点击间隔**
   - 在"点击间隔"输入框中输入间隔时间（单位：分钟）
   - 支持1-120分钟的范围

2. **选择点击模式**
   - `random`：在指定区域内随机点击
   - `center`：在区域中心点点击
   - `custom`：自定义点击区域

3. **设置点击区域**
   - 点击"设置区域"按钮
   - 在5秒内将鼠标移动到区域左上角
   - 再在5秒内将鼠标移动到区域右下角
   - 程序会自动记录区域范围

4. **启动/停止**
   - 点击"启动"按钮开始自动点击
   - 点击"停止"按钮停止自动点击
   - 或使用快捷键 F6 快速切换

### 高级设置

- **防止系统锁屏**：勾选后程序会阻止系统自动锁屏
- **开机自动启动**：勾选后程序会在系统启动时自动运行

### 测试功能

点击"测试点击"按钮可以在不启动自动点击的情况下测试点击功能。

## 配置文件

配置文件保存在用户主目录下：
- Windows: `C:\Users\<用户名>\.auto_clicker_config.json`
- macOS: `/Users/<用户名>/.auto_clicker_config.json`

## 日志文件

日志文件保存在用户主目录下：
- Windows: `C:\Users\<用户名>\.auto_clicker_logs\`
- macOS: `/Users/<用户名>/.auto_clicker_logs/`

## 注意事项

1. **权限要求**
   - Windows: 可能需要管理员权限来设置开机自启动
   - macOS: 需要在"系统偏好设置 > 安全性与隐私 > 辅助功能"中授权

2. **虚拟桌面兼容**
   - 支持Windows虚拟桌面
   - 支持macOS多桌面空间

3. **性能影响**
   - 程序采用低资源设计
   - 后台运行时CPU占用极低
   - 内存占用约20-30MB

4. **安全提示**
   - 请勿在需要精确操作的场景使用
   - 建议先使用测试功能验证点击位置
   - 长时间无人值守时建议监控运行状态

## 常见问题

### Q: 为什么点击没有生效？
A: 请检查：
1. 是否有足够的权限
2. 目标程序是否在前台
3. 点击区域设置是否正确

### Q: 如何取消开机自启动？
A: 取消勾选"开机自动启动"选项，或手动删除注册表项/启动项。

### Q: 程序运行时电脑会锁屏吗？
A: 如果勾选了"防止系统锁屏"选项，程序会阻止系统自动锁屏。

### Q: 如何在虚拟桌面中使用？
A: 程序支持虚拟桌面，可以在不同的虚拟桌面中正常工作。
