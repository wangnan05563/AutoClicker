## 5. 工程债 / 发布债

1. **打包形态**：`--onefile` 本机首次解包约 34 秒，PRD 目标冷启动 <3 秒；应切 `--onedir`，同步改 `build_exe.py`、`build_package.ps1`、`publish_package.ps1`、`installer.nsi`、README 产物说明。
2. **版本双轨**：`release.version` 与 `package.json` 仍两套口径；需构建生成 `auto_clicker_layers/version.py`，标题/关于/安装包/README 统一读取。
3. **配置 schema**：当前 `config_version=2`，PRD 要求 `schema_version: 3`；需迁移、备份、兼容旧键，并补迁移测试。
4. **安装包一致性**：`installer.nsi` 默认装到 `$LOCALAPPDATA\Programs\AutoClicker`，实际机器在 `F:\Program Files\AutoClicker`；注册表/卸载项/快捷方式需核对。
5. **依赖清单**：`requirements_py3.txt` 仍写 `cx-Freeze`，实际用 PyInstaller；需清理或标注历史用途。
6. **README 口径**：仍写“单文件产物”“ydotool 尚未接入”，但代码已实现 ydotool 后端、且准备切 onedir。
7. **崩溃日志治理**：`crash.log` 只追加不轮转；需按大小/日期轮转，避免长期运行膨胀。
8. **临时目录治理**：`C:\pyfix_tmp` 已有历史 `_MEI*` 残留；可在启动时清理“非当前进程占用”的旧目录，或随 onedir 迁移自然消失。
9. **测试缺口**：只有 GUI 冒烟“建窗/关窗”，没有完整交互回归；需补首启向导、主题切换、暂停/继续、录制回放、正常退出的自动化/半自动用例。
10. **发布链路**：新 exe 未生成新 NSIS 包、未更新 GitHub Release、未写更新说明；发布前需按 PRD 门禁跑 8h/DPI/主题/1024×768。
