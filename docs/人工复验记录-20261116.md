## 本轮修复

1. **深色主题只改变量、不落控件**：纯 ttk 无 ttkbootstrap 时，vista 主题忽略颜色设置，切换深色后画面仍为浅色。新增 `_apply_ttk_theme_styles()`，深色改用 clam 并统一配置 TFrame/TLabel/TLabelframe/TEntry/TCombobox/TCheckbutton/TScale/TProgressbar/TScrollbar/Treeview 等样式；新增 `_recolor_semantic_labels()` 同步状态/成功/失败/主色标签与画布。
2. **高 DPI 下窗口固定 720×800 导致按钮被挤成 1px**：改为按 `tk scaling / 1.3333` 计算窗口与最小尺寸，上限为屏幕 90%。100% 720×800、125% 900×972、150% 1078×972、200% 1440×972。
3. 配置方案行 combo 14→11、按钮间距 5→2，100% 下「导入」不再被压缩。
4. `on_theme_change()` 同步 `theme_var`，程序化切主题时下拉框不再残留旧值。
5. **托盘图标误报失败与多实例类冲突（T05257）**：pywin32 的 `Shell_NotifyIcon` 成功时返回 `None`，原 `if result:` 把成功误判为失败，导致托盘状态不同步；改为按异常判断。托盘窗口类名追加 PID，避免多实例 `RegisterClass` 冲突。新增 `_refresh_tray_icon()` 与浅/深两套 `tray_light.ico`/`tray_dark.ico`（各含 16/32 两档），主题切换时同步刷新 hicon；修掉 `_update_tray_status` 每次启停累积分隔线的问题。
6. **物理热键回调线程直接访问 Tk（T05212/T05215/T05229）**：`keyboard.add_hotkey` 回调运行在监听线程，调用 `toggle_clicking/emergency_stop` 会读 Tk 变量并抛 `main thread is not in main loop`，F6 启动直接失败。新增 `_hotkey_queue` + 主线程 `_poll_hotkey_queue`（50ms），热键回调只投递 `toggle/emergency`。
7. **后台点击线程直接 `root.after` 与主线程 `join` 互相等待**：修复前急停调用耗时 2.02s、3s 后点击线程仍 alive，线程栈卡在 `tkinter._register/createcommand`。新增 `_ui_queue` + 主线程 `_poll_ui_queue`（30ms），`_ui()` 只入队；`run_clicking` 的运行时计时启停也改为经主线程队列执行。
8. **后台线程读取 Tk 变量导致点击循环报错**：`_effective_interval_seconds`、`get_click_position`、`_move_before_click`、`_click_once_at`、`click_loop` 原来直接调用 `interval_var/mode_var/mouse_follow_var/mouse_speed_var/mouse_move_only_var/prevent_sleep_var.get()`；启动时缓存 `interval_seconds_cache` 等值，后台只读缓存。
9. **日志控件与停止复位从后台线程直写 Tk**：`log_message` 改为后台线程经 `_ui_queue` 渲染；`stop_clicking` 的 UI 复位抽为 `_apply_stopped_ui()`，非主线程调用时入队，修复自动停止（点击上限/failsafe）时状态条/按钮不复位。
10. **T05214 线程安全并发复验**：真实点击循环 20 次、点击上限自动停止，`threading.excepthook`/Tk `report_callback_exception` 无跨线程异常；计数标签与状态在主线程正确刷新，点击线程退出。
11. **T05218 运行参数热更新**：运行中 `interval_entry` 保持可编辑；`interval_var`/`interval_unit_var` trace 经 120ms 防抖更新 `interval_seconds_cache`，`_wait_interval` 每 50ms 检查 `_interval_change_event` 并立即按新间隔重算，2s→100ms 实测即时生效且 5 次点击计数连续。
12. **T05282 部署指南同步**：`docs/银河麒麟部署指南.md` 新增「V2 功能配置与平台注意事项」（主题三模式、配置方案、DPI 100/125/150/200%、运行统计导出、Wayland/X11 限制与 ydotool 说明），补充 FAQ，并修正系统要求处缺失的 Markdown 加粗标记。
