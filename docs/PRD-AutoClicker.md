## 1. 背景与问题定义

### 1.1 产品现状

AutoClicker 是单文件 Tkinter 应用（`auto_clicker_py3.py`，1424 行），定位「长时间低频点击 + 防锁屏」，已在 Windows 与银河麒麟部署使用。核心能力：间隔点击、三种取点模式、防锁屏、鼠标跟随/只移动、托盘常驻、单实例、F6 启停。

### 1.2 用户痛点（均经代码审计确认）

| # | 痛点 | 用户可感知表现 |
|---|---|---|
| P1 | 「测试点击」是假的 | 点确认后弹「测试成功」，实际未点击；正式运行才发现坐标打在空处 |
| P2 | 长跑可能崩 | 工作线程直接刷新界面，连续运行数小时后卡死或 Tcl 报错 |
| P3 | 取区域很别扭 | 固定 5 秒倒计时 + 弹窗，手速稍慢就取错；期间界面卡死 10 秒 |
| P4 | 节奏不可调 | 只能按「秒」设定，最细 1 秒；无随机抖动，节奏机械 |
| P5 | 能力偏窄 | 只能左键单击，右键菜单、双击打开、长按拖拽都不支持 |
| P6 | 停不下来 / 停不准 | 只能手动 F6；无法「点 100 次就停」「跑 30 分钟就停」 |
| P7 | 日志淹没问题 | 每次点击写 3–4 行，跑一夜后日志区全是噪声，且不落盘 |
| P8 | 只有中文浅色一种样子 | 无深色模式；麒麟环境缺字体时中文回退难看；图标用 emoji，跨平台不一致 |

### 1.3 竞品结论（摘要，详见需求基线 §2）

- 竞品分三派：极简点击（OP/GS/Speed）、参数面板（XClicker）、录制回放（KeymouseGo/AHK）。
- 本品唯一结构性优势是**会话保持**，但竞品集体缺失的这块恰恰对「值守/挂机/远程在线」最值钱。
- 本品最大能力差距是**毫秒级间隔**与**可控性（次数/时长上限、急停）**。
- 因此产品策略：不追功能数量，把「**长时无人值守的可靠性 + 企业部署可控性**」做实。

## 2. 产品目标与成功指标

### 2.1 一句话定位

> 一个能连续跑一整夜也不崩、随时能停得下来、在企业内网可审计可批量部署的桌面点击值守工具。

### 2.2 目标与关键结果

| 目标 | 关键结果（KR） |
|---|---|
| O1 让「长跑」真正可信 | KR1 连续运行 8 h 无崩溃/无 Tcl 异常；KR2 内存增长 ≤ 5 MB/8 h，峰值 ≤ 60 MB |
| O2 让「停」随时生效 | KR3 三条急停通道（托盘 / 全局 Esc / 鼠标甩角）均在 200 ms 内停止；KR4 停止指令响应 ≤ 200 ms |
| O3 让「节奏」够用 | KR5 支持 1 ms–24 h，10 ms 间隔下 1000 次均值偏差 < 5% |
| O4 让「上手」更快 | KR6 新用户从启动到首次成功运行 < 60 s；KR7 主流程 1024×768 下无需滚动 |
| O5 让「部署」可控 | KR8 单文件产物 ≤ 40 MB，冷启动 < 3 s；KR9 配置可导入导出、可批量预置 |

### 2.3 非目标（明确不做）

1. 不做反检测/绕过反作弊，不提供「防封号」能力承诺。
2. 不做进程注入、内存修改、驱动级隐藏。
3. 不做无提示的后台静默点击（默认托盘可见、状态可查）。
4. 不做全功能脚本引擎（录制回放仅「点击 + 按键 + 延时」最小集）。

## 3. 用户与场景

### 3.1 用户角色

| 角色 | 特征 | 核心诉求 | 占比预估 |
|---|---|---|---|
| 值守运维（R1） | 企业内网、麒麟桌面、需长时间保持会话在线 | 稳定、防锁屏、可远程确认状态、可批量部署 | 50% |
| 办公自动化（R2） | 固定系统里做重复录入/刷新/保存 | 精确取点、次数与时长可控、出错能停 | 35% |
| 个人挂机（R3） | 单机、游戏/挂机类 | 毫秒级、随机化、快捷键顺手 | 15% |

> 说明：R3 仅满足「拟人节奏」的技术能力，不为其规避平台规则背书（见 §2.3）。

### 3.2 核心场景

**S1 夜间值守（R1）**
运维下班前设定「每 60 秒点一次右下角状态区，跑 8 小时，结束后提示」，锁屏失效需确保不锁屏。次日早上查看统计：点击 480 次、0 异常。

**S2 单据批量保存（R2）**
在固定业务系统里，每 3 秒点一次「保存」，共 200 次，中途弹窗遮挡需自动暂停并告警。

**S3 首次使用（R3）**
下载单文件 exe，双击打开，选「挂机连点」预设，框选屏幕区域，按 F6 开始，全程 60 秒内完成。

### 3.3 用户旅程（首启 → 运行 → 收尾）

| 阶段 | 用户动作 | 产品响应 | 关键要求 |
|---|---|---|---|
| 首启 | 双击启动 | 3 步引导（场景 → 区域 → 热键） | 可跳过；跳过则用上次配置 |
| 配置 | 设间隔/取区域/选停止条件 | 即时校验、实时预览坐标 | 非法值不弹窗、行内提示 |
| 启动 | 点「启动」或按热键 | 若开安全模式则二次确认；状态条变运行色 | 停止条件与剩余量可见 |
| 运行 | 最小化到托盘 | 托盘 tooltip 显示「运行中·剩余 12s」 | 界面操作不阻塞点击线程 |
| 收尾 | 自动停止 / 手动停止 | 弹出摘要（次数/时长/异常），会话保持复原 | 复原必须与启用严格对称 |

```
┌──────────────────────────────────────────────────────────┐
│ 状态条：● 运行中 · 剩余 00:12 · 已点击 37 次            │
├──────────┬───────────────────────────────────────────────┤
│ 常用      │  内容区（随导航切换）                          │
│ 高级      │  · 常用：间隔 / 取点 / 停止条件 / 主操作        │

│          │  · 关于：版本 / 路径 / 许可 / 检查更新          │
├──────────┴───────────────────────────────────────────────┤
│ 主操作条：[▶ 开始 (F6)]  [■ 停止]      倒计时环 00:12    │
└──────────────────────────────────────────────────────────┘
```

**约束**：主操作条固定底部常驻；导航不超过 4 项；1024×768 与 1280×800 下主流程不出现垂直滚动。

### 6.1 模块 A：运行控制与状态（对应 T05202）

## 8. 关键交互规范

### 8.1 取区域（FR-C01）

| 步骤 | 交互 | 反馈 |
|---|---|---|
| 1 | 点「取区域」 | 全屏变暗 40%，显示提示条「拖拽框选区域 · 单击取点 · Esc 取消」 |
| 2 | 按下并拖拽 | 实时绘制选框 + 尺寸标签 `W×H (x,y)`；右键撤销当前框 |
| 3 | 松开 | 选框保留 1 s 后关闭遮罩，回填「区域」字段并更新预览 |
| 4 | Esc | 立即关闭遮罩，原值不变，提示「已取消」 |

### 8.2 启动与急停（FR-E01/E02）

| 场景 | 行为 |
|---|---|
| 点「开始」 | 安全模式开启 → 摘要确认框（间隔 / 目标 / 停止条件 / 热键）；确认后 3 s 倒计时启动（可 Esc 取消） |
| 运行中 | 状态条转运行色，主操作条按钮变「停止」，托盘 tooltip 更新 |
| 急停触发 | 立即停止 → 会话保持复原 → 状态条转「已停止」→ 日志记一条 `EMERGENCY_STOP reason=corner/esc/tray` |
| 停止后 | 弹非模态摘要条（本次 N 次 / 时长 / 异常），5 s 后自动隐藏 |

### 8.3 错误提示分级

| 级别 | 形式 | 示例 |
|---|---|---|
| 字段级 | 行内红字（不弹窗） | 「间隔需 ≥ 1 ms」 |
| 操作级 | 顶部横幅（可关闭） | 「Wayland 会话不支持模拟输入，启动已禁用」 |
| 致命级 | 模态对话框 + 日志 | 「配置文件损坏，已备份为 config.bad.json 并恢复默认」 |

## 14. 风险与依赖

| 风险 | 影响 | 应对 |
|---|---|---|
| ttk 主题能力有上限（复杂动效/圆角） | 视觉达不到设计稿 | 视觉规范限定在 ttk 可实现范围；M2 后若确有需要再评估 PySide6 迁移 |
| Wayland 强制 uinput 权限 | 部分国产终端无法模拟输入 | FR-L01 明确降级与指引；文档标注「推荐 X11 会话」 |
| 无 arm64 麒麟真机 | 打包/点击未验证 | 用交叉编译产物 + 借用环境冒烟；在风险登记中挂起 |
| PyInstaller 单文件启动慢 | 首启体验差 | NFR-05 设 3 s 门槛；必要时改 onedir + 快捷方式 |
| 需求蔓延（录制回放/图像识别） | 拖慢 P0 | §2.3 非目标硬约束，变更需走评审 |
| 双基线文档（v1/v2）并存 | 开发取错口径 | v2 为唯一基线，v1 已标注归档 |

### 依赖

- 代码基线：`auto_clicker_py3.py`（重构为五层，见 NFR-09）
- 平台工具：`python-xlib`、`pystray`、`Pillow`、`keyboard`；Wayland 需 `ydotool`/`ydotoold`
- 打包：PyInstaller；文档：`docs/银河麒麟部署指南.md` 需同步更新
