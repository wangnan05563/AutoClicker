# 运行台状态与今日统计

FR-26 的运行台由三部分组成：左侧状态环、右侧运行详情/今日统计、底部启停操作条。状态环同时承担状态与倒计时，顶部状态条、窗口标题、运行台使用同一状态源。

## 1. 状态与颜色

| 状态 | 触发 | 状态环颜色 | 环中心 | 右侧详情 | 主操作 |
|---|---|---|---|---|---|
| 已停止 | 未运行 | 中性灰 | 已停止 / 等待开始 | 等待开始 | 启动可用 |
| 运行中 | 点击线程运行 | 绿色满环 | 运行中 / MM:SS | 已运行时间 · 本次点击 | 停止可用 |
| 倒计时 | 启动倒计时 1–5 秒 | 蓝色按剩余比例收缩 | 倒计时 / X.Xs | 剩余 X.X 秒后开始 | 停止=取消 |
| 异常 | 连续 3 次点击失败且成功数为 0，或点击异常 | 红色满环 | 异常 / 查看诊断 | 运行中：点击线程仍在继续，可按 F8/Esc 停止；已停止：请查看诊断 | 停止或查看诊断 |
| 暂停 | R2 实现 | 黄色 | 暂停 | 暂停原因 | R2 |

异常时顶栏、窗口标题、运行台同步进入异常态；具体原因只在红色“原因：…”行展示一次，避免重复。运行中异常不自动终止点击线程，用户可按 F8/Esc 或“停止”结束。

## 2. 今日统计

统计文件：`~/.auto_clicker_daily_stats.json`，schema `autoclicker.daily-stats/1`。

| 字段 | 类型 | 说明 |
|---|---|---|
| `schema` | string | 固定 `autoclicker.daily-stats/1` |
| `date` | string | 本地日期 `YYYY-MM-DD`；跨天读取自动归零 |
| `click_count` | int | 当日点击总数 |
| `success_count` | int | 当日成功点击数，不超过点击数 |
| `fail_count` | int | 当日失败点击数，不超过点击数 |
| `exception_count` | int | 当日点击异常次数 |
| `run_count` | int | 当日运行次数 |
| `runtime_seconds` | float | 当日累计运行秒数 |

运行中展示值为“已落盘基线 + 当前会话”，不提前写盘；停止或运行中退出时一次性累加并保存。`save` 使用同目录临时文件 + `os.replace` 原子替换，坏 JSON 读取为空统计，不阻塞启动。

## 3. 隐私与边界

- 只保存聚合计数，不保存点击坐标、点击区域、窗口标题、进程名、配置内容或日志。
- 统计文件位于用户主目录，随用户配置一起由用户自行保管；诊断包也不包含该文件。
- 今日成功率按“成功数/点击数”计算；点击数为 0 时显示 `--`。
- 上次运行摘要来自会话快照，包含点击数、成功率和运行时长；不写入统计文件。

## 4. 倒计时精度

启动倒计时使用 `time.monotonic()` 截止时间 + 100ms 轮询，状态环按剩余比例收缩，环中心保留一位小数秒，例如 `3.0s`；状态条整秒文案只在秒数变化时更新，减少重绘。PRD 要求显示误差 `<200ms`。
