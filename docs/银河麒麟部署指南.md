## 系统要求

### 硬件要求
- **处理器：双核及以上处理器
- **内存：** 2GB 及以上
- **硬盘空间：** 至少 500MB 可用空间

### 软件要求
- **操作系统：** 银河麒麟桌面操作系统 V10 SP1 (x86_64/arm64)
- **Python 版本：** Python 3.8 及以上（推荐 Python 3.9-3.12）

## 安装部署方式

### 方式一：从源代码运行（推荐用于开发测试）

#### 1. 安装系统依赖

打开终端，执行以下命令安装必要的系统依赖：

```bash
# 更新软件包列表
sudo apt update

# 安装 Python3 和 pip
sudo apt install -y python3 python3-pip python3-dev

# 安装 X11 开发库（用于 python-xlib）
sudo apt install -y libx11-dev libxtst-dev

# 安装 Pillow 依赖
sudo apt install -y libjpeg-dev zlib1g-dev

# 安装 Tkinter
sudo apt install -y python3-tk
```

#### 2. 克隆或下载项目

```bash
cd ~
# 如果使用 git 克隆（如果有 git）
# git clone <仓库地址>
# 或者直接解压项目文件到本地目录
```

#### 3. 进入项目目录

```bash
cd auto_clicker
```

#### 4. 安装 Python 依赖

```bash
# 使用 Linux 专用的 requirements 文件
pip3 install -r requirements_linux.txt
```

或者逐个安装依赖：

```bash
pip3 install pyautogui keyboard python-xlib pystray Pillow
```

#### 5. 运行程序

```bash
python3 auto_clicker_py3.py
```

---

### 方式二：打包为可执行文件（推荐用于生产部署）

#### 1. 完成方式一的步骤 1-4

#### 2. 安装 PyInstaller

```bash
pip3 install pyinstaller
```

#### 3. 使用配置文件打包

```bash
# 使用提供的 spec 文件打包
pyinstaller setup_pyinstaller_linux.spec
```

或者直接打包：

```bash
pyinstaller --onefile --windowed --name="AutoClicker" auto_clicker_py3.py
```

#### 4. 查找生成的可执行文件

打包完成后，可执行文件位于：
```
dist/AutoClicker
```

#### 5. 测试运行

```bash
cd dist
./AutoClicker
```

## 从源代码运行

### 创建桌面快捷方式

1. 创建桌面启动器文件：

```bash
nano ~/.local/share/applications/AutoClicker.desktop
```

2. 粘贴以下内容（根据实际路径修改）：

```desktop
[Desktop Entry]
Type=Application
Name=自动点击工具
Comment=桌面自动点击工具
Exec=/path/to/auto_clicker_py3.py
Icon=/path/to/icons/tray.png
Terminal=false
Categories=Utility;
Keywords=click;autoclick;
StartupWMClass=AutoClicker
```

3. 保存并退出（Ctrl+X，然后 Y，然后 Enter）

4. 设置执行权限：

```bash
chmod +x ~/.local/share/applications/AutoClicker.desktop
```

5. 给 Python 脚本添加执行权限：

```bash
chmod +x /path/to/auto_clicker_py3.py
```

## 打包为可执行文件

### 创建系统集成

1. 将打包好的可执行文件复制到系统目录：

```bash
sudo cp dist/AutoClicker /usr/local/bin/
sudo chmod +x /usr/local/bin/AutoClicker
```

2. 创建图标目录：

```bash
sudo mkdir -p /usr/local/share/AutoClicker/icons
sudo cp icons/* /usr/local/share/AutoClicker/icons/
```

3. 创建系统级桌面快捷方式：

```bash
sudo nano /usr/share/applications/AutoClicker.desktop
```

粘贴以下内容：

```desktop
[Desktop Entry]
Type=Application
Name=自动点击工具
Comment=桌面自动点击工具
Exec=/usr/local/bin/AutoClicker
Icon=/usr/local/share/AutoClicker/icons/tray.png
Terminal=false
Categories=Utility;
Keywords=click;autoclick;
StartupWMClass=AutoClicker
```

## 常见问题

### Q: 鼠标点击没有生效？

A: 请检查：
1. 是否有足够的权限
2. 目标程序是否在前台
3. 点击区域设置是否正确
4. X11 是否正确配置

### Q: 如何授予程序鼠标控制权限？

A: 在银河麒麟中，程序默认具有鼠标控制权限。如果遇到问题，可以尝试：

```bash
# 检查 X11 权限
xhost +local:
```

### Q: 系统托盘图标不显示？

A: 确保安装了 pystray 和 Pillow：
```bash
pip3 install pystray Pillow
```

### Q: 防止系统休眠功能不工作？

A: 确保安装了 xset 和 xdg-screensaver：
```bash
sudo apt install -y x11-xserver-utils xdg-utils
```

### Q: 快捷键不工作？

A: keyboard 模块在 Linux 上可能需要 root 权限：
```bash
sudo python3 auto_clicker_py3.py
```

或者使用其他方式实现快捷键功能。

## 卸载说明

### 从源代码运行的卸载

```bash
# 删除程序文件
rm -rf /path/to/auto_clicker

# 删除配置文件
rm -f ~/.auto_clicker_config_py3.json

# 删除锁文件
rm -f ~/.autoclicker.lock

# 删除桌面快捷方式
rm -f ~/.local/share/applications/AutoClicker.desktop
```

### 系统级安装的卸载

```bash
# 删除可执行文件
sudo rm -f /usr/local/bin/AutoClicker

# 删除图标
sudo rm -rf /usr/local/share/AutoClicker

# 删除桌面快捷方式
sudo rm -f /usr/share/applications/AutoClicker.desktop

# 删除用户配置
rm -f ~/.auto_clicker_config_py3.json
rm -f ~/.autoclicker.lock
```
