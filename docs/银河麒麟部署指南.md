## 系统要求

### 硬件要求
- **处理器：** 双核及以上处理器
- **内存：** 2GB 及以上
- **硬盘空间：** 至少 500MB 可用空间

### 软件要求
- **操作系统：** 银河麒麟桌面操作系统 V10 SP1 (x86_64/arm64)
- **Python 版本：** Python 3.8 及以上（推荐 Python 3.9-3.14）
- **显示协议：** 推荐 X11；Wayland 会话下本版本会禁用启动并提示改用 X11（见下文）

## 安装部署方式

### 方式一：从源代码运行（推荐用于开发测试）

#### 1. 安装系统依赖

打开终端，执行以下命令安装必要的系统依赖：

```bash
# 更新软件包列表
sudo apt update

# 安装 Python3 和 pip
sudo apt install -y python3 python3-pip python3-dev

# 安装 X11 开发库（用于 python-xlib）
sudo apt install -y libx11-dev libxtst-dev

# 安装 Pillow 依赖
sudo apt install -y libjpeg-dev zlib1g-dev

# 安装 Tkinter
sudo apt install -y python3-tk
```

#### 2. 克隆或下载项目

```bash
cd ~
# 如果使用 git 克隆（如果有 git）
# git clone <仓库地址>
# 或者直接解压项目文件到本地目录
```

#### 3. 进入项目目录

```bash
cd auto_clicker
```

#### 4. 安装 Python 依赖

```bash
# 使用 Linux 专用的 requirements 文件
pip3 install -r requirements_linux.txt
```

或者逐个安装依赖：

```bash
pip3 install pyautogui keyboard python-xlib pystray Pillow
```

#### 5. 运行程序

```bash
python3 auto_clicker_py3.py
```

---

### 方式二：打包为可执行文件（推荐用于生产部署）

#### 1. 完成方式一的步骤 1-4

#### 2. 安装 PyInstaller

```bash
pip3 install pyinstaller
```

#### 3. 使用配置文件打包

```bash
# 使用提供的 spec 文件打包（spec 已移至 scripts/，需在项目根目录执行）
pyinstaller scripts/setup_pyinstaller_linux.spec
```

或者直接打包：

```bash
pyinstaller --onefile --windowed --name="AutoClicker" auto_clicker_py3.py
```

#### 4. 查找生成的可执行文件

打包完成后，可执行文件位于：
```
dist/AutoClicker
```

#### 5. 测试运行

```bash
cd dist
./AutoClicker
```

## 从源代码运行

### 创建桌面快捷方式

1. 创建桌面启动器文件：

```bash
nano ~/.local/share/applications/AutoClicker.desktop
```

2. 粘贴以下内容（根据实际路径修改）：

```desktop
[Desktop Entry]
Type=Application
Name=自动点击工具
Comment=桌面自动点击工具
Exec=/path/to/auto_clicker_py3.py
Icon=/path/to/icons/tray.png
Terminal=false
Categories=Utility;
Keywords=click;autoclick;
StartupWMClass=AutoClicker
```

3. 保存并退出（Ctrl+X，然后 Y，然后 Enter）

4. 设置执行权限：

```bash
chmod +x ~/.local/share/applications/AutoClicker.desktop
```

5. 给 Python 脚本添加执行权限：

```bash
chmod +x /path/to/auto_clicker_py3.py
```

## 打包为可执行文件

### 创建系统集成

1. 将打包好的可执行文件复制到系统目录：

```bash
sudo cp dist/AutoClicker /usr/local/bin/
sudo chmod +x /usr/local/bin/AutoClicker
```

2. 创建图标目录：

```bash
sudo mkdir -p /usr/local/share/AutoClicker/icons
sudo cp icons/* /usr/local/share/AutoClicker/icons/
```

3. 创建系统级桌面快捷方式：

```bash
sudo nano /usr/share/applications/AutoClicker.desktop
```

粘贴以下内容：

```desktop
[Desktop Entry]
Type=Application
Name=自动点击工具
Comment=桌面自动点击工具
Exec=/usr/local/bin/AutoClicker
Icon=/usr/local/share/AutoClicker/icons/tray.png
Terminal=false
Categories=Utility;
Keywords=click;autoclick;
StartupWMClass=AutoClicker
```

## V2 功能配置与平台注意事项

### 主题与界面

- 支持「浅色 / 深色 / 跟随系统」三种主题；切换后主窗口、卡片、输入框、下拉框、状态标签和托盘图标同步刷新。
- 无 `ttkbootstrap` 时，深色主题使用 Tk 内置 `clam` 主题承载颜色；浅色主题在 Windows 使用 `vista`，Linux 使用 `clam`。
- 配置持久化在 `~/.auto_clicker_config_py3.json` 的 `theme_mode` 字段；重启后保持上次选择。

### 首次运行与配置方案

- 首次启动会写入「推荐安全」预设：启动前 3 秒倒计时、点击次数/时长上限、failsafe 开关等安全默认值。
- 「高级 (P1)」区域支持配置方案：保存当前、切换、删除、导出 JSON、导入 JSON；方案保存在 `profiles` 字段，`current_profile` 记录当前方案。

### DPI 与窗口缩放

- 启动时按 Tk `scaling` 自动计算窗口与最小尺寸，避免高 DPI 下按钮被压缩；100%/125%/150%/200% 缩放下控件不裁切。
- 点击坐标使用物理像素，进程启动前已开启 DPI 感知，缩放比例不会改变实际点击落点。
- 若桌面缩放异常，建议先切回 100% 复核，再逐步提高系统缩放。

### 运行统计导出

- 每次运行结束后记录最近一次会话快照：时间、点击数、成功/失败数、运行时长、间隔、模式、按键。
- 「高级 (P1)」区域的「导出运行统计」可导出 JSON 或 CSV；无有效点击记录时会提示暂无可导出数据。
- 导出文件仅包含统计数据，不包含屏幕内容或用户输入内容。

### Wayland 限制（重要）

- 本版本输入后端依赖 X11（pyautogui/python-xlib）；Wayland 会话下启动会被禁用，并在顶部显示可关闭的提示横幅。
- 推荐在登录界面选择「X11 / Xorg」会话后再运行；具体判定矩阵、日志诊断和手动降级步骤见 [`docs/Wayland降级说明.md`](Wayland降级说明.md)。
- 当前版本未接入 `ydotool` 输入后端；检测到 `ydotool` 时仍会提示本版本不支持，不会静默假装可用。
- 本文档基于当前 V2 代码同步；银河麒麟 V10 SP1 x86_64/arm64 真机部署仍需按发布检查表复核，尤其是 arm64 与 Wayland 组合。

## 常见问题

### Q: 鼠标点击没有生效？

A: 请检查：
1. 是否有足够的权限
2. 目标程序是否在前台
3. 点击区域设置是否正确
4. X11 是否正确配置

### Q: 如何授予程序鼠标控制权限？

A: 在银河麒麟中，程序默认具有鼠标控制权限。如果遇到问题，可以尝试：

```bash
# 检查 X11 权限
xhost +local:
```

### Q: 系统托盘图标不显示？

A: 确保安装了 pystray 和 Pillow：
```bash
pip3 install pystray Pillow
```

### Q: 防止系统休眠功能不工作？

A: 确保安装了 xset 和 xdg-screensaver：
```bash
sudo apt install -y x11-xserver-utils xdg-utils
```

### Q: 快捷键不工作？

A: keyboard 模块在 Linux 上可能需要 root 权限：
```bash
sudo python3 auto_clicker_py3.py
```

或者使用其他方式实现快捷键功能。

### Q: 深色主题切换后部分控件仍是浅色？

A: 确认使用的是最新版本；程序会在深色模式切到 Tk `clam` 主题并重配 ttk 样式。若仍未生效，检查是否有旧配置覆盖 `theme_mode`，并查看「打开日志目录」中的主题初始化日志。

### Q: 高 DPI 下窗口太大或按钮被压缩？

A: 程序会按系统缩放自动计算窗口，无需手工改 720×800。若界面异常，先确认系统缩放比例，再重启程序让 DPI 感知重新初始化；必要时在 100% 缩放下复核。

### Q: 运行统计导出为空？

A: 导出只针对「最近一次已完成运行」；至少完成一次有效点击后才会生成快照。启动后立刻停止、没有点击时，导出会提示暂无可导出数据。

### Q: Wayland 会话下无法启动？

A: 这是本版本的明确限制，不是安装失败。请退出当前会话，在登录界面选择 X11/Xorg 后重新登录；详细判定矩阵和日志诊断见 `docs/Wayland降级说明.md`。

## 卸载说明

### 从源代码运行的卸载

```bash
# 删除程序文件
rm -rf /path/to/auto_clicker

# 删除配置文件
rm -f ~/.auto_clicker_config_py3.json

# 删除锁文件
rm -f ~/.autoclicker.lock

# 删除桌面快捷方式
rm -f ~/.local/share/applications/AutoClicker.desktop
```

### 系统级安装的卸载

```bash
# 删除可执行文件
sudo rm -f /usr/local/bin/AutoClicker

# 删除图标
sudo rm -rf /usr/local/share/AutoClicker

# 删除桌面快捷方式
sudo rm -f /usr/share/applications/AutoClicker.desktop

# 删除用户配置
rm -f ~/.auto_clicker_config_py3.json
rm -f ~/.autoclicker.lock
```
