# 产物体积验证报告（T05268 / REQ-006）

- 日期：2026-11-16
- 环境：Windows 10 Pro 19045，Python 3.14.3，PyInstaller 6.20.0
- 构建命令：`PyInstaller --onefile --windowed`，入口 `auto_clicker_py3.py`，含 icons 与 pyautogui/keyboard/PIL/win32 hidden imports
- 产物：`D:\code\otherProjects\AutoClicker\release\dist_size\AutoClickerSize.exe`
- 结论：**单文件 21.38 MiB，满足 <40 MB；产物可正常启动并出现主窗口，REQ-006 体积门槛通过。**

## 1. 体积实测

| 产物 | 字节 | MiB | 门槛 |
|---|---:|---:|---|
| `AutoClickerSize.exe`（当前代码） | 22,417,288 | 21.38 | <40 MiB，通过 |
| 旧 `release\dist\AutoClicker.exe`（8:48 构建） | 33,663,534 | 32.10 | <40 MiB，通过 |

说明：1 MiB = 1,048,576 字节。当前产物比旧产物小约 11.2 MiB，主要因为本轮将 pyautogui/keyboard 的启动期导入链改为懒加载，冻结内容与运行期资源占用同步收敛。

## 2. 可启动性验证

- 使用隔离环境变量 `AUTOCLICKER_MUTEX_NAME=AutoClicker_SizeTest_Fresh`、`AUTOCLICKER_WINDOW_TITLE=AutoClicker Size Test Fresh` 启动，未影响用户正在运行的 AutoClicker。
- 实测主窗口出现（`MainWindowHandle != 0`，标题匹配），进程可正常创建窗口；测试后已清理全部 `AutoClickerSize` 测试进程。
- 启动耗时记录：onefile 从 `Start-Process` 到主窗口出现约 **23.5s**（onefile 每次解压临时目录导致；与体积任务无关，但作为 T05267/T05277 的打包策略证据保留）。

## 3. 结论

- REQ-006 的「单文件 <40 MB」硬指标满足，产物可启动，T05268 可标 `verified=true`。
- 体积达标不代表启动达标：onefile 解压开销使启动约 23.5s，明显劣于 onedir 的约 4.2s；启动性能仍由 T05267 继续，打包策略取舍由 T05250 评估。
