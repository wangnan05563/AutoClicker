# AutoClicker

<p align="center">
  <img src="docs/social-preview.png" alt="AutoClicker" width="640" />
</p>

一个轻量的桌面自动点击工具，支持自定义点击间隔、点击区域、防锁屏与快捷键控制，支持 Windows 与 Linux（银河麒麟）。

## 功能特性

- 自定义点击间隔（秒 / 毫秒 两种单位，支持 0-100% 随机抖动）
- 三种点击模式：随机位置 / 中心点 / 自定义区域
- 鼠标按键选择（左 / 右 / 中 / 双击）与按住时长（毫秒）
- 多点位序列点击（屏幕坐标拾取 + 手动输入 + 列表管理）
- 防止系统自动锁屏：独立后台保活（勾选即生效，不依赖点击运行），周期性断言系统/显示器唤醒并做 1px 鼠标微抖动，可击败策略型锁屏与屏保
- 快捷键可自定义（默认启动/停止 F6，紧急停止 F8；Esc 始终为紧急停止）
- 启动倒计时、点击次数上限、运行时长上限（安全可控）
- 鼠标移动即停（failsafe，可选）
- 鼠标跟随移动与「只移动不点击」模式（仅移动光标、不产生点击）
- 「测试点击位置」按钮：移动光标并执行一次真实点击，用于确认目标点
- 多套配置方案：保存 / 切换 / 删除 / 导入导出 JSON
- 开机自动启动（Windows 注册表 / Linux autostart）
- 后台低资源运行（内存约 20-30MB）
- 实时状态显示与运行日志（应用内 + 磁盘 `~/.auto_clicker_logs/autoclicker.log`，RotatingFileHandler 5MB×5）
- 信息架构：顶部固定状态条 + 左侧运行台/规则/记录/设置四项导航 + 底部固定启停操作条；1024×768 主流程不依赖滚动
- 版本双轨：产品版本与日期构建号分离，窗口标题、关于页、`--version`、构建产物同源
- 五套内置主题（晨曦 / 深空 / 高对比 / 海洋蓝 / 暖沙）与跟随系统，运行时切换并持久化；支持导入 JSON 用户主题包（仅颜色令牌，不执行脚本）
- 简单/高级双模式：Simple 只保留间隔、目标、次数/时长与防锁屏；Advanced 展开节奏、多点、调度、前台窗口、鼠标跟随与记录页，切换不重置参数
- 首次运行 3 步向导：选场景（保持在线/挂机签到/固定按钮连点/自定义）→取目标→确认热键；可跳过并写入推荐安全方案，设置页可重跑
- 高 DPI 适配：进程级 DPI 感知（保证点击坐标准确）+ 按系统缩放调整 UI 渲染
- 运行统计导出：结束一次运行后点击「导出运行统计」，可将点击数 / 成功 / 失败 / 运行时长等导出为 JSON 或 CSV
- Wayland 降级保护：Linux 启动自动检测会话类型，纯 Wayland 下显示横幅、禁用启动与测试点击并给出 X11/ydotool 指引（不静默失败）

## 系统要求

- Windows 10/11 或 Linux（银河麒麟等）
- Python 3.7+

## 快速开始

```bash
# 安装依赖
pip install -r requirements_py3.txt

# 运行
python auto_clicker_py3.py
```

## 打包为可执行文件

```bash
python scripts/build_exe.py
```

每次打包前会先生成当天唯一的构建版本号（`YYYYMMDD-序号`，如 `20261115-001`）并写回根 `package.json` 的 `version` 字段；双击 `scripts/构建打包.bat` 与直接运行 `build_exe.py` 走同一套逻辑，保证每次构建的版本号不重复。

产物输出至 `release/dist/AutoClicker/AutoClicker.exe`（onedir 目录，分发时需携带同目录依赖；安装包/zip 已包含全部文件）。

## 使用说明

1. 设置点击间隔（秒 或 毫秒，可选 0-100% 随机抖动；间隔单位通过「间隔单位」切换）
2. 选择点击模式：`random`（区域内随机）/ `center`（中心点）/ `custom`（自定义区域）；或使用「多点位序列」按列表循环点击
3. 选择鼠标按键与按住时长；点击「设置区域」，依次将鼠标移至区域左上角和右下角完成录制
4. 点击「启动自动点击」或按自定义启动键开始自动点击；运行中可按紧急停止键 / Esc 急停；托盘菜单会随运行状态显示「启动点击/停止点击」

配置保存在用户主目录下（`~/.auto_clicker_config_py3.json`）；运行日志实时显示在应用内，并落盘至 `~/.auto_clicker_logs/autoclicker.log`（可在「配置方案/系统」卡片点击「打开日志目录」）。

> 注意：Windows 设置开机自启动可能需要管理员权限；Linux 需在系统辅助功能设置中授权。
